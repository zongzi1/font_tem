2.

返回的是：

UseMutationResult

里面有很多东西：

loginMutation.mutate

loginMutation.mutateAsync

loginMutation.isPending

loginMutation.isSuccess

loginMutation.error
----------------------------------------------
对，可以这么理解。

mutateAsync() 本质上返回一个 Promise。

例如：

const result = await loginMutation.mutateAsync({
  email,
  password
});

底层相当于：

return new Promise(...)
成功时

如果 mutationFn 成功：

mutationFn: ({ email, password }) =>
  authApi.login(email, password)

返回：

{
  "user": {...},
  "accessToken": "...",
  "refreshToken": "..."
}

那么：

const result = await loginMutation.mutateAsync(...);

这里的：

result

就是：

{
  "user": {...},
  "accessToken": "...",
  "refreshToken": "..."
}
失败时

例如后端返回：

401 Unauthorized

或者：

500 Internal Server Error

那么：

await loginMutation.mutateAsync(...)

会直接：

throw error;

等价于：

Promise.reject(error)

所以必须：

try {

  await loginMutation.mutateAsync({
    email,
    password
  });

} catch (error) {

  console.log(error);

}
等价写法

下面两段完全等价：

mutateAsync
try {

  const data =
    await loginMutation.mutateAsync(param);

} catch (error) {

}
Promise
loginMutation
  .mutateAsync(param)
  .then(data => {

  })
  .catch(error => {

  });

通常这样写：

const onSubmit = async (
  data: LoginForm

  try {

      await loginMutation.mutateAsync(data);

    router.push('/dashboard');

  } catch (error) {

  }

}
